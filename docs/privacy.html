Docs-and-Claims

Privacy policy

Last updated: 7 September 2026

Docs-and-Claims is a private-use application that reads verification emails from Gmail. This policy covers its Gmail integration, which is not offered as a public service.

Access and use

With authorization, the integration checks the connected account address and reads matching verification messages to retrieve sign-in codes. Before entering an accepted code into the sign-in page, it marks only that verification message as read by removing Gmail's Unread label. Other messages and labels are left unchanged.

The Gmail permission (gmail.modify) covers the entire mailbox, not just matching messages. It also permits other actions, including sending email and moving messages to Trash. The integration does not use those capabilities: it does not send, archive, or delete email, and its only email change is marking the accepted verification message as read.

Sharing

Codes are entered into the service that issued them for the requested sign-in. The integration does not otherwise share message content, sell Gmail data, use it for advertising, or send it to AI systems.

Retention and control

Message content and codes are processed during sign-in and are not retained as application records. The saved authorization credential is kept for future use until removed. Original messages remain in Gmail.

Access can be revoked through Google Account connections. The saved credential can also be removed. Revoking access does not itself erase the saved credential or Gmail messages.

Protection

Encrypted connections and operating-system security controls protect authorization information. No system can guarantee absolute security.

Use of Google data follows the Google API Services User Data Policy, including its Limited Use requirements.

Changes

Material changes to data handling will be reflected here before they take effect.
